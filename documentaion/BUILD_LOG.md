# ApnaCircle implementation record

## Validation policy

The owner requested source authoring and feature-by-feature Git commits/pushes without installing dependencies, running application code, or executing tests in this workspace. Each step receives source review and Git whitespace/diff inspection. Compilation, automated checks, database execution, device testing, screenshots, and release builds remain **pending local execution**. A written check is not a passing check.

1. Agreed product documentation and repository baseline.

Each commit is created when that step is authored and reviewed. Dates are the actual commit dates; no history is backdated.

## Composer and media recovery — source authored

Added validated post composition, native photo selection, bounded JPEG preparation and immutable uploads. Each submission freezes one UUID/text/photo snapshot. Active tab switches retain the draft; explicit discard/back removal asks for confirmation. Session/account unmount clears in-memory drafts.

Source review: traced cancellation, denial, upload failure, lost insert response, duplicate UUID and late-account results. Added runnable recovery checks. Permission dialogs, image bytes, navigation guards, database races and the rendered composer require local native testing.
