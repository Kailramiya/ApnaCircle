# ApnaCircle implementation record

## Validation policy

The owner requested source authoring and feature-by-feature Git commits/pushes without installing dependencies, running application code, or executing tests in this workspace. Each step receives source review and Git whitespace/diff inspection. Compilation, automated checks, database execution, device testing, screenshots, and release builds remain **pending local execution**. A written check is not a passing check.

## Feature sequence

1. Agreed product documentation and repository baseline.
2. Expo/TypeScript foundation and shared design components.
3. Supabase schema, RLS, storage, and reproducible demo seed.
4. Authentication, session lifecycle, and bilingual onboarding.
5. Paginated community feed, search, and filters.
6. Post composer, image upload, and retry recovery.
7. Likes, comments, and saved posts.
8. Jobs, saved jobs, applications, and history.
9. Profile editing, settings, and in-app notifications.
10. Regression checks, local verification instructions, and release preparation.

Each commit is created when that step is authored and reviewed. Dates are the actual commit dates; no history is backdated.
